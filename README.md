# Itameshi website draft

Responsive static restaurant website concept for the empty `riyowna/Itameshi` repository.

## Preview

Open `index.html` directly in a browser or serve this folder with a static HTTP server. There is no build step or package installation.

## Business details and verification

- The supplied Facebook page could not be fetched in the research environment, so its branding and official menu were not confirmed.
- A third-party Restaurant Guru listing for “Itameshi restaurant” lists 21 W 2nd St, Olongapo and +63 966 964 6641. The site labels both as directory details that need owner confirmation.
- A separate listing exists for “Itameshi Cafe” at 38 Hansen St with a different phone number. It was not treated as the same business and none of its details were used.
- Restaurant Guru mentions pasta, pizza, teriyaki chicken, and chahan, but no exact menu or prices were asserted. Menu cards are intentionally category-level concepts pending the official menu.
- Food artwork is original CSS illustration, not restaurant photography. Replace it with owner-approved photos before launch.

## Files

- `index.html` — page structure and draft content
- `styles.css` — responsive layout, styling, and original decorative illustrations
- `script.js` — menu filters and mobile navigation
